# BNI KeyCore Dashboard

Este projeto é um dashboard para visualizar, gerenciar e entender a estrutura e os membros do grupo empresarial BNI JUNTOS. Ele foi desenvolvido em React e utiliza bibliotecas modernas para interatividade e componentes reutilizáveis.

## Funcionalidades
- **Membros**: Listagem detalhada dos membros do grupo com busca e integração.
- **Grafo**: Visualização de conexões e interações entre membros.
- **Fit**: Ferramenta básica de análise de compatibilidade entre membros ou atividades.
- **Página de grupo (estrutura e valores)**: Explicação detalhada do método e história do BNI.

## Tecnologias
- **React**: Framework JS modular e moderno.
- **React Router**: Navegação entre as várias páginas e componentes.
- **D3.js**: Criação de grafos dinâmicos e interativos.
- **Material-UI (MUI)**: Design clean e responsivo.

## Requisitos
Certifique-se de ter as seguintes dependências instaladas:
- Node.js (versão 18 ou superior recomendado)
- npm (ou yarn)

## Como rodar
1. Clone o repositório:
```bash
git clone https://github.com/KeyCoreSH/bni-keycore-dashboard
cd bni-keycore-dashboard
```
2. Instale as dependências:
```bash
npm install
```
3. Execute o servidor de desenvolvimento:
```bash
npm start
```
4. Navegue para `http://localhost:3000` no seu navegador.
